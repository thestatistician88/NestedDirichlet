# NestedDirichlet

This repository consists of two main files:
  - NDD_MASTER_FunctionsOnly.R 
  - NDD_Demo.Rmd
  
The R script contains a large number of functions to generate, work with, 
and estimate compositional data that follow the Nested Dirichlet distribution 
(NDD). The demo markdown file serves as a vignette to highlight the functions core 
utilities which include:
  - Generating random numbers
  - Theoretical mean, variance, and correlation computations
  - Theoretical pdf and cdf for the marginals
  - Tree Plotting framework
  - Parameter estimation of the NDD (tree known and unknown)
  - Model diagnostics to asses the fit
